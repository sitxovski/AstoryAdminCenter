# AdminCenter — запуск и остановка админ-центра Astory

`AdminCenter.bat` управляет службой панели на dev-сервере (`@@ASTORY_SERVER_VPN_IP@@`, только по SSH, ключ `%USERPROFILE%\.ssh\@@ASTORY_SSH_KEY_NAME@@`).
Двойной клик открывает меню. Можно запускать и с аргументом: `AdminCenter.bat status`.

| Команда | Что делает |
|---|---|
| `status` | показывает задачу планировщика `AsdaAdminCenter`, процесс панели (PID, с какого времени), обёртку `run_service.bat` и отвечает ли панель (`/api/me` → 401 = жива) |
| `start` | запускает задачу и ждёт до 40 с, пока панель ответит. Если служба уже работает — ничего не делает |
| `stop` | останавливает задачу, процесс панели и обёртку (иначе обёртка подняла бы панель через 10 с). Спросит «ДА» |
| `restart` | `stop`, затем `start`. Спросит «ДА» |
| `tunnel` | панель на этом ПК по адресу **https://localhost:17890/** (SSH-туннель к серверу) и открывает её в браузере. Работает, пока открыто окно; Ctrl+C или закрыть окно — туннель закрыт. `--no-browser` — не открывать браузер |

`--yes` пропускает вопрос: `AdminCenter.bat restart --yes`.
Коды возврата: 0 — ок, 1 — панель не отвечает или не остановилась, 2 — ошибка SSH, 3 — отменено или неизвестная команда.

**Что не трогается:** игровая стойка, файлы и настройки службы, брандмауэр, задача планировщика (только запуск/остановка),
бот Oracle на ПК (Discord и Telegram). Обновление кода панели — не здесь, а `python AstoryAdminCenter\deploy\deploy_admin_center.py`.

**Пока служба остановлена:** панель недоступна всем, задания по расписанию панели (выключение событий, бэкапы БД, суточные
отчёты) не выполняются, уведомления в Telegram не ставятся. После загрузки сервера служба поднимается сама.

Логика — `AstoryAdminCenter\deploy\admin_center_ctl.py`. Журнал службы на сервере — `@@ASTORY_SERVER_ROOT@@\AdminCenter\logs\service.log`.

## Что умеет панель

Адрес: **https://@@ASTORY_SERVER_VPN_IP@@:17890/** (VPN) или **https://localhost:17890/** через `tunnel` — если браузер ходит через
системный прокси (такой прокси может не пускать к адресу VPN, а `localhost` он обходит). Через туннель вход для
службы идёт с самого сервера, как из VPN. Подробности, роли и вход — `AstoryAdminCenter\GUIDE.md`,
справка по каждой операции — раздел «Справка» в самой панели.

| Раздел | Для чего |
|---|---|
| Состояние | процессы стойки, базы, мост, общая сводка |
| Игроки | поиск учётки и персонажа, карточки, правки с журналом и откатом |
| Кто в игре | кто сейчас онлайн (по мосту) |
| След предмета / Поиск дюпов | откуда и куда ходил предмет, подозрительные копии |
| Данные игры: магазины | наборы изменений магазинов и данных игры |
| Журналы стойки | хвост серверных журналов |
| Античит, суточный отчёт, автоблок и EAC, дела | журнал античита, флаги за день, автоблоки, дела AC-NNNN |
| Очередь имён | проверка новых и сменённых имён |
| Жалобы игроков | жалобы из бота Discord: разбор, ответ автору |
| Журнал чата | чат игры и заглушки |
| Посещаемость | счёт и дни посещаемости, ручные отметки |
| Выпуски | каналы выпуска, срок подписи, снимок ПК (только статус) |
| Сбои клиента | места падений, частота, версии |
| Очередь Discord | объявления в Discord: статус, повтор, отмена |
| Заметки к выпуску | черновик заметок для игроков из changelog и публикация |
| Сообщество | заявки, тестеры, предупреждения, баны Discord, команды боту |
| Telegram владельцу | выключатели уведомлений, проверка, очередь |
| Деньги / Экономика / Передачи и рынок / Шансы | монетизация, потоки золота, передачи, выпало против заявленного |
| Журнал действий | кто что сделал в панели, откат записей |
| Справка | что меняет каждая операция, нужен ли перезапуск, можно ли откатить |
| Пользователи панели / О себе | пользователи и роли, свой пароль и второй фактор |
